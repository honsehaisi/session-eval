# 大肥鱼测评 · 桌面版 1.0.10

把「会话日志评测算分工具」包成双击就能用的 Windows 应用。
**读日志 → 八维打分 → 出一份单文件 HTML 报告**，跑一轮约 1–4 分钟。

八维：速度 / 稳定 / 成本 / 交付 / 安全 / 诚实 / 记忆 / 一致性。**八维现在都能测**，但工作量不一样——前六维点一下自动出分，记忆和一致性要自己准备题库和作答（见下面「八项各测什么、怎么出分」）。

## 怎么用

1. 把整个 `大肥鱼测评-win32-x64` 文件夹原样放着，别拆
2. 双击 `大肥鱼测评.exe`，第一次打开是欢迎页
3. 点右下角「重新测评」跑一轮（约 1–4 分钟），报告自动刷新
4. 想改数据源点「设置」；不清楚怎么接就点「使用方式」

## 数据源

- 用 DSH：默认读 `~/.dsh/sessions`，点「重新测评」就行
- 用别的 AI：导出「一行一条」的 JSONL，设置里切 `generic` 并填字段名（见 README §5 / 给AI的使用方式.md）
- 没日志：先空跑看界面，等攒了日志再测

## 八项各测什么、怎么出分

| 维度 | 测什么 | 要你做什么 |
|---|---|---|
| 速度 | 所有轮次耗时的中位数 + 任务段耗时 | 不用管，日志有时间戳就自动算 |
| 稳定 | 工具调用失败率 + 异常结束占比 | 不用管；日志没有成功/失败字段会标「无法判断」 |
| 成本 | 每次有效会话的平均花费 | 不用管；日志要有 token 用量 |
| 交付 | 多少比例的会话真产出了东西（写文件、跑命令） | 用别的工具时，设置里配「产物工具名」 |
| 安全 | 规则表扫危险动作（删文件、外传、绕过授权） | 不用管；通用日志只覆盖 33 条，A 不代表绝对安全 |
| 诚实 | 说「完成了」之后有没有真去验证 | 不用管；断言太少会未覆盖 |
| 记忆 | 记不记得自己的记忆库 | **要自己出题 + 作答**（见下） |
| 一致性 | 同一套题隔段时间问两遍，答案稳不稳 | **要题库 + 作答两次 + 判分**（见下） |

前六维：点「重新测评」全自动，跑完看报告就行。

**记忆**（要自己的记忆库，没有库这一维没意义）：

1. 出题：在 `resources/eval` 下用 `node src/memory/gen.js --auto` 扫自己的记忆库生成草稿，抽检改写后 `--merge` 落成 `src/memory/questions.json`（包里不自带题库，得自己出）
2. 设置页「记忆题库文件」可以留空（留空就用刚落的 `src/memory/questions.json`），题库放别处就指过去
3. `ask.js` 出提问单 → 作答（人工或让 AI 代答，别让它查答案）→ `judge.js` 判分 → `score.js` 出分
4. 把 `src/memory/report.json` 填到设置页「记忆证据文件」

**一致性**（要有题库 + 记忆库 + 隔开时间问两遍）：

1. 先有题库（可以就用记忆那步生成的题库；包里不答题库，没题库这一步跑不起来）和题面模板
2. `snapshot.js` 记库快照 → `ask.js` 出第一份提问单 → 作答
3. 隔 ≥1 天，用同一份计划再问一遍 → 作答
4. `judge.js` 比两次答案 → `score.js` 出一致率
5. 把 `report-t1.json` 填到设置页「一致性证据文件」

上面带命令的步骤可以直接照抄给 AI 助手，`给AI的使用方式.md` 第 7 节有逐条说明和坑。

## 为什么会有格子显示「未覆盖」

「未覆盖」= 这次没有算这一格需要的数据，**不是 0 分**，也不拉低综合分（分母里剔掉再归一）。八格都覆盖才是完整评级。

| 常见原因 | 怎么办 |
|---|---|
| 日志里没有 token / 时间戳 / 工具事件 | 换一份完整日志，或让 AI 补导出字段 |
| 记忆 / 一致性没填证据文件 | 按「八项各测什么」做一遍，再填设置页 |
| 断言太少（诚实）/ 没有不可逆动作（安全 A2） | 样本不够，属正常，等日志攒够 |

## 数据放在哪

| 东西 | 位置 |
|---|---|
| 程序本体 | `大肥鱼测评-win32-x64/`（整个目录一起拷走才能用） |
| 运行时副本 | `%APPDATA%\大肥鱼测评\runtime\` |
| 配置文件 | `%APPDATA%\大肥鱼测评\runtime\config.json` |

版式/模板/表情图随包走，运行时按包内 `build-id` 判断要不要重铺；`config.json` 不会被覆盖，所以设置能保住。记忆/一致性的证据文件填在本机路径，也随本机保留。

## 已知限制

1. 记忆、一致性是手工活，要作答；想一键出八维暂时做不到
2. 一致性两次作答要隔 ≥1 天，同一天连问两遍测不出「稳不稳」
3. 没有代码签名 → SmartScreen 首次会提示「未知发布者」，点「更多信息 → 仍要运行」
4. 杀软可能拦 Electron 打包的 exe，属常见误报
5. 只能放**可写目录**运行（不要放 Program Files）
6. 从带 `ELECTRON_RUN_AS_NODE=1` 的终端里启动会被当成 node 跑而报错；双击不受影响
7. 包体约 350MB，主要是 Electron 运行时

## 排查

- `大肥鱼测评.exe --selftest --no-sandbox`：不开窗口，只准备运行时，结果写到 `%TEMP%\fe-selftest.json`
- 窗口不出来：试目录里的 `打不开就试这个.cmd`（加 `--no-sandbox`）
- 某格「未覆盖」：看报告里那一格的来源说明，或 `runtime` 目录下 `report.json` 的 `dims.<维度>.source`

## 用安装程序装的

- 装到 `%LOCALAPPDATA%\Programs\大肥鱼测评`（当前用户，不需要管理员）
- 桌面 + 开始菜单都有快捷方式（程序 / 使用说明 / 卸载）
- 卸载在「设置 → 应用」或开始菜单；卸载时会问要不要删 `%APPDATA%\大肥鱼测评`（运行时缓存与配置），默认保留
- 覆盖安装直接装同一位置即可，装前会检查程序是否在运行
